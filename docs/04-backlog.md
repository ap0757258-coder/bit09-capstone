# Project Backlog

## Phase 1: Discovery (Days 1-2)
- Read capstone requirements
- Document problem analysis
- Write user stories
- Define MVP scope
- Create backlog
- First git commit

## Phase 2: Design (Days 3-4)
- Design database schema
- Design REST API endpoints
- Create architecture diagram
- Design UI wireframes
- Define security rules

## Phase 3: Implementation (Days 5-18)
- Backend setup (Days 5-8)
- Backend core APIs (Days 9-12)
- Security and logging (Days 13-14)
- Backend testing (Day 15)
- Frontend setup and components (Days 16-22)

## Phase 4: Documentation (Days 24-26)
- Write evaluation dossier
- Create user guide
- Record demo video
- Final submission
