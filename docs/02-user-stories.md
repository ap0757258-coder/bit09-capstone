# User Stories - BIT-09 Capstone

## Student User Stories

### US-001: Submit Document Request
As a student, I want to submit a request for a bonafide letter so that I can get the document for admission.

### US-002: Check Request Status
As a student, I want to check the status of my request so that I know when my document will be ready.

### US-003: Download Signed Document
As a student, I want to download my approved document so that I can use it for my purpose.

### US-004: Verify Document Authenticity
As a student, I want to verify that my document is genuine so that I can prove it wasn't forged.

## Admin User Stories

### US-005: View Pending Requests
As an admin, I want to see all submitted requests so that I can process them quickly.

### US-006: Check Student Eligibility
As an admin, I want to verify student eligibility so that only eligible students get documents.

### US-007: Approve/Reject Requests
As an admin, I want to approve or reject requests with one click so that I can process documents fast.

### US-008: View Audit Trail
As an admin, I want to see complete history of all actions so that I can audit for compliance.

## Security User Stories

### US-009: Secure Authentication
As a system, I want to require login so that only authorized users access the system.

### US-010: Digital Signatures
As a system, I want to digitally sign documents so that they can't be forged.
