# MVP Scope - What We WILL Build

## Essential Features
- User authentication (login/signup)
- Service catalog (list documents)
- Request form (students submit)
- Eligibility checking (auto-verify)
- Approval workflow (admin approves)
- Document signing and download
- Audit logging (track all actions)
- Basic admin dashboard

## Features We WON'T Build
- Email notifications
- SMS notifications
- Mobile app (web only)
- Multiple languages
- Advanced analytics
- DevOps/CI-CD pipeline

## Acceptance Gates - DON'T DO
- Don't build CRUD-only portal
- Don't deploy without testing
- Don't ignore security
- Don't have dashboard-only submission
- Don't copy code without attribution

## Technology Stack
- Backend: Spring Boot 3.x, PostgreSQL 17
- Frontend: React 18+
- Auth: JWT tokens
- Database: PostgreSQL 17
